### 1.6 分析问题（请逐条回答）

**Q1：Adam 和 SGD 的收敛速度有何差异？从实验结果中你观察到了什么？**

Adam 优化器的收敛速度远快于 SGD：
Exp1（SGD）需要约 45 个 Epoch 才能收敛，最低 Loss 仅 0.098，测试准确率 0.965；
Exp2（Adam）仅需 20 个 Epoch 收敛，最低 Loss 降至 0.045，测试准确率提升至 0.976。
原因是 Adam 结合了动量和自适应学习率机制，能根据参数梯度动态调整更新步长，而 SGD 采用固定学习率，更新方向仅依赖当前批次梯度，收敛效率低。同时观察到 SGD 后期 Loss 有轻微上升趋势，而 Adam 收敛后 Loss 更稳定。

**Q2：学习率对训练稳定性有什么影响？**

学习率直接影响训练稳定性：
过大的学习率（如 Exp1 中 SGD 的 0.01）会导致参数更新幅度过大，Loss 曲线震荡明显，甚至可能无法收敛；
过小的学习率会使收敛速度极慢，训练后期参数更新几乎停滞；
合适的学习率（如 Adam 的 0.001）能让 Loss 平稳下降，训练过程稳定。
在最终模型中调整为 0.0008 的学习率，进一步降低了训练震荡，同时保证了收敛速度，验证了学习率需在 “收敛速度” 和 “稳定性” 之间平衡。

**Q3：Batch Size 对模型泛化能力有什么影响？**

Batch Size 对泛化能力的影响体现在：
较小的 Batch Size（64）：训练数据多样性更高，梯度更新更频繁，模型能学习到更细粒度的特征，但训练速度稍慢；
较大的 Batch Size（128，Exp3）：训练效率更高，梯度估计更稳定，减少了批次噪声，但可能导致模型过度拟合训练数据的整体分布，泛化能力略有下降。
实验中 Exp3（Batch=128）训练准确率 0.981 略低于 Exp2（0.985），但验证准确率 0.979 略高，说明适当增大 Batch Size 可提升训练稳定性，但需配合早停等策略避免过拟合。

**Q4：Early Stopping 是否有效防止了过拟合？**

Early Stopping 有效防止了过拟合：
Exp2（无 Early Stopping）训练准确率 0.985，验证准确率 0.978，存在轻微过拟合；
Exp3（有 Early Stopping）训练准确率 0.981，验证准确率 0.979，训练 / 验证准确率差距缩小，且提前在 18 轮停止训练，避免了后期对训练数据的过度拟合。
Early Stopping 通过监控验证集 Loss / 准确率，当验证性能不再提升时停止训练，截断了过拟合的过程，是简单且有效的正则化手段。

**Q5：数据增强是否提升了模型的泛化能力？为什么？**

数据增强显著提升了模型泛化能力：
Exp4（使用数据增强）测试准确率 0.980，相比 Exp2（无增强）的 0.976 提升 0.4%，验证准确率从 0.978 提升至 0.982；
原因是数据增强（旋转、仿射变换）扩充了训练数据的多样性，让模型学习到数字在不同角度、位置下的特征，减少了对 “固定位置 / 角度数字” 的过拟合；
同时数据增强相当于给训练数据添加噪声，迫使模型学习更鲁棒的特征表示，从而在测试集上表现更好。
